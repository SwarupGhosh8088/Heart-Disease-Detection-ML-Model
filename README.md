# Heart-Disease-Detection-ML-Model

❤️ Heart Disease Detection Using Machine Learning

📌 Project Overview

This project focuses on predicting the possibility of heart disease using Machine Learning techniques. It uses patient medical attributes to train a classification model that can identify whether a person is likely to have heart disease.

The project demonstrates the complete Machine Learning workflow, including data preprocessing, exploratory data analysis, visualization, model training, and evaluation.

🎯 Objectives

- Analyze medical data to identify patterns related to heart disease.
- Perform data cleaning and preprocessing.
- Explore relationships between different medical attributes.
- Train a Machine Learning classification model.
- Evaluate model performance using appropriate metrics.

🛠️ Technologies Used

- Programming Language: Python
- Libraries:
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
  - Scikit-learn
- Environment: Jupyter Notebook

📊 Dataset Features

The dataset contains the following attributes:

Feature| Description
age| Age of the patient
sex| Sex of the patient
cp| Chest pain type
trestbps| Resting blood pressure
chol| Serum cholesterol
fbs| Fasting blood sugar
restecg| Resting ECG results
thalach| Maximum heart rate achieved
exang| Exercise-induced angina
oldpeak| ST depression
slope| Slope of the ST segment
ca| Number of major vessels
thal| Thalassemia
target| Heart disease indicator

⚙️ Project Workflow

1. Data Collection: Load the heart disease dataset.
2. Data Preprocessing: Check missing values, clean the data, and prepare features.
3. Exploratory Data Analysis: Analyze data distributions and relationships using visualizations.
4. Feature Selection: Identify relevant features for prediction.
5. Model Training: Train a Machine Learning classification algorithm.
6. Model Evaluation: Evaluate the trained model using classification metrics.

📈 Model Evaluation

The model is evaluated using classification performance metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
